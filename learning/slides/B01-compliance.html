CEX 交易所系统 · 幕后核心 · B01

点一下提币，要穿过几道看不见的检查

  1. 你在交易所点了一下提币，几秒钟后钱就上链了。但在这几秒里，它要穿过好几道看不见的检查。
  2. 第一层是账户安全。登录风险评分、2FA 或 Passkey、敏感操作冷却期，确认操作的是本人。
  3. 第二层是合规，也就是本集的主题。KYC 等级与限额、制裁与地理筛查。还有 KYT 地址风险和 Travel Rule 信息。
  4. 后面还有业务风控、资金正确性和平台安全。每层只拦自己负责的风险。单独一层都会漏，叠在一起才可靠，这就是纵深防御。
  5. 任何一层发现严重异常，都会升级到应急响应。这像机场，乘客只看到值机柜台，幕后有护照查验、安检和消防队。
  6. 这是幕后核心的第一集。本集只讲系统设计，不构成法律意见，以监管原文为准。除标注公开资料外，阈值都是示例。

Threat Model · Regulatory Map · 截至 2026 年公开资料

要防什么

  1. 先看威胁模型。合规要防六类事：洗钱、恐怖融资、制裁规避。还有欺诈资金流入、无牌经营和消费者保护违规。
  2. 洗钱的手法是放置、分层、整合，比如拆分、多跳、跨链和 P2P 套现。制裁规避靠借用账户、VPN 和中间地址。后果从罚款一直到刑事责任。
  3. 规则从哪来？源头是 FATF，金融行动特别工作组。它只发布标准。各国写进国内法后，交易所才有法定义务。
  4. 建议15要求各国监管虚拟资产服务商 VASP。建议16要求转账附带双方信息，这就是 Travel Rule。FATF 的门槛是1000美元或欧元。
  5. 各地落地不同。根据公开资料，欧盟 MiCA 在2024年12月30日全面适用。TFR 同日适用，加密转账没有最低金额豁免。据公开报道，币安 FZE 在2024年4月获得迪拜 VARA 完整牌照。
  6. 美国有银行保密法、FinCEN 和 OFAC 制裁。制裁不看金额，没有小额豁免。牌照状态变化很快，应以监管机构的登记册为准。
Layered Defense

六层防线：每层拦一部分，也漏一部分

  1. 合规防线分六层。第1层是准入，拦假证件、名单上的人和受限地区居民。它漏过账户买卖、出借和深度伪造。
  2. 第2层是交易前检查，包括充值和提币 KYT，以及 Travel Rule。它秒级同步，拦住直接来自制裁地址或混币器的钱。漏过的是多跳之后的间接资金。
  3. 第3层是交易后监控，规则加模型，异步告警。它发现拆分、快进快出和异常 P2P，漏过新手法。
  4. 第4层调查。第5层处置，报告、冻结或退出关系。第6层治理，不拦资金，只检查前五层是否按规则运转。
  5. 两个规律。下一层要补上一层的漏洞。越靠后越慢、越贵，第4层靠人工，产能有上限。
KYC / KYB Lifecycle

KYC 不是一次性的：认证、复审、再认证

  1. 第一条关键流程，KYC 生命周期。用户提交证件，企业提交资料，进入准入审核。企业客户叫 KYB，还要识别最终受益所有人。
  2. 标准核验叫 CDD。通过后按评分进入低风险或中风险。评分高或是政治公众人物，进入强化尽调 EDD。制裁命中或资料造假，直接退出。
  3. 准入只是起点。客户一直在认证、复审、再认证的循环里。定期复审按评级定周期，触发式复审由事件驱动。
  4. 典型触发事件有五个。更新国籍或居住地，名单更新后出现新匹配，告警被确认为真，收到协查函，证件到期。
  5. 资料过期没更新，账户进入受限。受限不等于冻结，通常只许提出。超期不补交，就退出关系。局限是，账户被转卖后，状态机看不见。
Customer Risk Rating · 示例模型

因子加权打分：输出的是复审周期

  1. 评分怎么打？业界通常用因子加权打分。示例模型有六个因子，从地域、客户类型，一直到历史告警。
  2. 算一个示例客户。一般地区10分，企业客户10分，不是政治公众人物0分。
  3. 高频使用 P2P，15分。交易量与收入不匹配，20分。没有确认告警，0分。合计55分。
  4. 示例规则：低于30分是低风险，3年复审。30到59分是中风险，2年复审。60分以上进入 EDD，每年复审。这位客户是中风险。
  5. 注意，评级输出的是复审周期和监控强度，不是放不放行。制裁命中不进评分，它是硬规则，命中就拦。
Transaction Monitoring → SAR / STR

引擎只生成告警，判断和报告靠人

  1. 第二条关键流程，交易监控。充值、提币、成交和 P2P 事件进入事件总线。监控引擎运行规则和模型，生成带证据的告警。
  2. 一线分析员领取告警。明显误报就关闭，但要写明理由。需要深入的，升级为案件。
  3. 调查员拉取 KYC、链上图谱、设备和 IP，把结论交给反洗钱报告官 MLRO。MLRO 签发报告，交给金融情报机构。美国叫 SAR，多数地区叫 STR。
  4. 报告有法定时限。例如美国通常要求30个日历日内提交。多数地区还禁止告诉客户他已被报告，客服话术要为此设计。
AML Graph · 规则场景示例

结构化拆分：每笔都不过线，合计过线

  1. 监控规则长什么样？先看结构化拆分，也叫 smurfing。把大额拆成小额，避开报告阈值。
  2. 示例阈值是10000 USDT。规则 TM-02：24小时内至少3笔，每笔在阈值的50%到100%之间。合计过线就告警。图上6000、7000、8000，合计21000，触发告警。
  3. 第二个是分层，也叫 layering，用多跳、跨链、换币切断来源。规则 TM-03：连续3跳以上，每跳都在时间窗口内，金额保留90%以上，就告警。
  4. 图上这笔钱走了4跳，中间跨了一次链。每跳只少一点手续费，几十分钟就转完。正常用户很少这样转钱。
  5. 其他示例规则还有：充值后2小时内提走90%以上。7天内和20个以上对手方做 P2P。5个以上账户共用一台设备。学生月交易额超过100万 USDT。
KYT · Direct / Indirect Exposure · 示例算法

风险分随跳数衰减

  1. 交易前的另一道防线是链上 KYT。服务商会给地址打标签，计算风险暴露。1跳内来自高风险实体，叫直接暴露。2跳以上，叫间接暴露。
  2. 示例算法：风险分等于基础分，乘以衰减系数的跳数减1次方，再乘以资金占比。跳数越多，分数越低。
  3. 代入示例。制裁地址基础分100，衰减系数0.5，资金占比40%。如果是直接暴露，风险分是100乘以0.4，等于40。
  4. 图上本平台充值地址离制裁地址3跳。100乘以0.5的平方，再乘以0.4，等于10。假设告警线是20，这笔不告警。
  5. 交易所这类聚合节点，混着大量正常资金。业界通常在这里停止追溯，否则全网地址都会被标红。
  6. 攻击者也懂这个算法。他用剥离链拉长跳数，让分数衰减到线下。拉长追溯能抓到它，但误报会增加。
Travel Rule · 信息走链下，和提币同行

Travel Rule：一封信，跟着一笔提币走

  1. 第三条关键流程，Travel Rule。VASP 转出资产时，要把双方信息传给接收方。所以用户提币时，还要填受益人姓名和对方平台。
  2. 钱包服务把请求交给 Travel Rule 网关。网关先查 VASP 目录，这个地址属于谁？这是最难的一步，因为地址不写明归属。
  3. 找到对方 VASP，网关就加密发送双方信息。对方确认受益人匹配后放行，再签名广播。注意，信息走链下，链上交易不带任何姓名。
  4. 如果对方是自托管钱包，目录里查不到。系统会要求用户证明地址所有权，或者补充声明。
  5. 字段以 FATF 释义为基础。发起方要姓名、账号，再加住址、证件号或出生日期之一。受益方要姓名和账号。各家协议不同，不互通时网关要转换。

第 2 步不能省

伪造执法函是已知诈骗手法 · 通过已知官方渠道回拨确认，不能只信来函上的联系方式
  1. 制裁筛查有三个维度。第一是姓名，做模糊匹配，处理音译和别名。难点是常见姓名误报高。
  2. 第二是地址，精确匹配名单上的链上地址，新地址靠图谱推断。第三是地理，用 IP 和居住地做地理围栏，难点是 VPN 和出差误杀。
  3. 名单是动态的。根据公开公告，OFAC 在2022年8月把 Tornado Cash 列入名单。2025年3月又把它移除。系统要支持双向变更，回溯筛查，并保留变更前的判定记录。
  4. 再看执法协作，一共五步。收到协查函或冻结令，核验真实性和管辖权，再按指令冻结。然后提供数据并记录，最后解冻、没收或返还。
  5. 第二步不能省。伪造执法函是已知的诈骗手法。要通过已知的官方渠道回拨确认，不能只信来函上的电话。
Case · 据公开报道和和解文件

2023 年和解：整改落在每一层

  1. 来看真实案例。据公开报道和和解文件，2023年11月，币安承认违反银行保密法和制裁规定。它同意支付约43亿美元。
  2. 按公开文件的叙述，早期增长优先，KYC 不强制。美国用户和受制裁地区用户可以交易，也没有提交可疑交易报告。我们的分析是，根因在于合规不是准入条件。
  3. 和解要求独立合规监察。司法部的监察员来自 Forensic Risk Alliance，任期3年。FinCEN 监察员来自 Sullivan and Cromwell，任期5年。
  4. 监察员不运营系统，只检查整改是否有效。整改落在每一层：强制 KYC、实时制裁筛查、监控和报告，还有历史交易回溯。
  5. 据公开报道，2025年曾讨论提前结束监察。2026年4月有参议员致信询问，结果以官方公告为准。启示是，漏报常在多年后暴露，判定记录必须完整保存。
Metrics · Trade-offs · 示例

误报与漏报：没有免费的答案

  1. 怎么衡量合规系统？看运营指标，以下都是示例。告警积压超过一线3天产能，处理时长 P90 超过7天，都要告警。
  2. 真阳性率低于2%，说明规则过宽。SAR 超时率大于0，复审逾期率超过5%，名单更新延迟超过24小时，也要告警。
  3. 核心权衡是误报和漏报。阈值严，告警淹没调查团队。阈值松，洗钱漏过去，换来处罚。真阳性率低于5%很常见，扩大覆盖会让告警成本线性上升。
  4. 常见做法是分层阈值，高风险客户收紧。体验和合规之间用分级 KYC。可解释性上，规则兜底，模型排序。隐私上，加密传输，最少字段。
Summary

记住三件事

  • 合规是纵深防御：准入看人，交易前看地址，交易后看行为。
  • KYC 是持续复审；告警由人判断再报告；Travel Rule 信息走链下。
  • 误报与漏报此消彼长；判定记录是多年后回溯的依据。

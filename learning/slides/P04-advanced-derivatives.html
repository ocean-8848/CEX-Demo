  1. 假设你有1个 BTC 现货，同时在永续上空了1个 BTC。价格怎么走，两条腿的盈亏基本抵消。可是分开算保证金，示例里要占12000 USDT。

  1. 本集分四段。第一，多资产保证金，不卖 BTC 也能做 U 本位合约。第二，统一账户和组合保证金，对冲仓位不再重复占用保证金。
  2. 第三，期权，买方和卖方的收益曲线完全不对称。第四，风险限额，平台为什么要给每个用户和每个市场设上限。
  3. 先打个比方。逐仓像给每辆车单独买保险。组合保证金像给整个车队买保险。一辆车往东开，一辆往西开，不会在同一场暴雨里同时出事，保费就便宜。
  4. 但比喻有局限。真实市场里，看似对冲的两个资产，可能同一天一起下跌。所以还要给车队设上限，这就是风险限额。
Multi-Assets Mode

多资产模式：BTC 不卖，按折算率计入保证金

  1. 先看多资产模式。根据币安公开资料，U 本位合约可以用多种资产作保证金。这个模式只支持全仓。2024年2月9日起，新开的合约账户默认开启。
  2. 资产按折算率计入。示例，1个 BTC，指数价100000，折算率97.5%。保证金价值就是97500 USDT，BTC 不用卖。
  3. 仓位亏损用 USDT 结算。USDT 不够，余额就变成负数。业界通常由平台把其他资产自动兑换成 USDT 补足，具体以官网为准。
  4. 注意一个局限。如果用 BTC 作保证金去做多 BTC 合约，BTC 一跌，抵押物和仓位同时亏。这就是 EP15 讲过的双重敞口。
  5. 和单资产相比，系统多了抵押物指数价和折算率两个依赖。根据公开报道，2025年10月10日，部分保证金资产短时偏离锚定，抵押账户被强平。

  1. 第二段，统一账户。根据币安公开资料，组合保证金 PM 把现货杠杆和两种合约放进一个账户。风险统一计算，另有 PM Pro 版本。
  2. 核心指标叫统一维持保证金率 uniMMR，等于账户调整后权益除以总维持保证金。这是简化示意，以官网为准。
  3. 调整后权益，是各资产按指数价和折算率估值，减负债，加未实现盈亏。分母按组合风险算，不是简单相加。
  4. 根据币安公开资料，uniMMR 低于1.05，也就是105%，就触发强平。另据公开报道，PM Pro 的口径排除了未平仓位的未实现亏损。
  5. 还有一点。币安会定期调整折算率。折算率一下调，uniMMR 立刻下降，哪怕用户什么都没做。
Scenario Stress Test · 业界通用做法

情景压力测试：两条腿的盈亏相互抵消

  1. 回到开场的例子。现货多1个 BTC，永续空1个 BTC，价格60000。分开算，各收10%示例保证金，合计12000。
  2. 分开算，现货跌了要追保，合约涨了也要追保。组合保证金改用情景压力测试，它是 CME 的 SPAN 等公开方法的简化。
  3. 先定义情景，示例从负15%到正15%，每5%一档。每一档重估整个组合。现货多头腿，负15%亏9000，正15%赚9000。有期权时，还要叠加波动率情景。
  4. 合约空头腿正好相反。负15%时赚9000，正15%时亏9000。
  5. 两条腿相加，每一档净盈亏都是0。取最差情景亏损作为风险保证金，这里是0。
  6. 但对冲不完美，有基差，还有资金费流出。所以平台加附加项，示例基差附加0.5%，就是300 USDT。保证金从12000降到300。
State Machine · 1.05 公开阈值 · 1.2 示例

统一账户的四个状态

  1. 再看统一账户的状态机。uniMMR 高于预警线时，账户处于正常状态。示例预警线是1.2。
  2. uniMMR 降到1.2，进入预警。用户可以补充资产，或者减仓，回到正常。
  3. 继续降到1.05及以下，进入强平中。1.05是公开阈值。
  4. 注意这条特别的边，从正常直接跳到强平中。原因是跳空，或者折算率下调。用户没有交易，账户也可能突然接近强平线。
  5. 进入强平中，业界通常先处理风险贡献最大的仓位，不会一次清空。部分强平后 uniMMR 恢复，就回到正常。全部仓位和负债处理完，才进入已清算。
Call Chain · 组件名为示意

每次价格变化，都要重跑全部情景

  1. 这套计算在系统里怎么跑？指数价服务推送指数价和标记价，送到组合风险引擎，组件名是示意。
  2. 风险引擎读取账户的全部仓位，再从账本读取全部资产和负债。
  3. 然后逐个情景重估盈亏，取最差值，算出 uniMMR。计算量是逐仓的数十倍，每次价格变化都要跑全部情景。
  4. uniMMR 小于等于1.05，就把强平任务和风险贡献排序，交给强平引擎。强平引擎按顺序减仓，再到账本结算强平分录。
  5. 工程上两个要点。业界通常按风险给账户分组，高风险的高频重算。另外，价格源一延迟，uniMMR 就滞后，期间的跳空会直接变成穿仓。

折算率调整 · 公开报道

2024–2026 年，币安多次公告下调 PM 抵押资产折算率。用户要在生效前补仓或减仓。

2025-10-10 · 公开报道

部分保证金资产短时偏离锚定 → 抵押账户被强平。统一账户放大影响面：一种抵押物出问题，整个组合受影响。
  1. 平台从组合保证金里赚什么？它不单独收费。保证金占用下降，同样的资金能开更大仓位，平台赚更多交易量和借贷利息。
  2. 主要用户是机构和做市商。做市商的双边报价天然对冲，组合保证金让他们用更少的资金，提供更深的流动性。
  3. 代价是新风险。首先是模型风险，情景可能小于真实行情，比如单日跌40%。兜底是回测、扩大情景、加集中度附加项。
  4. 其次是折算率风险和相关性失效。对冲资产可能同时下跌，所以业界通常不让跨标的对冲完全抵扣。还有连锁强平，大账户卖抵押物，又压低指数价。
  5. 看真实案例。根据公开报道，2024到2026年，币安多次公告下调抵押资产折算率。2025年10月10日那次，一种抵押物出问题，整个统一账户一起受影响。

  1. 第三段，期权。根据币安公开资料，币安期权是欧式期权，只能在到期日行权。到期前可以在市场上卖出平仓。
  2. 它用 USDT 现金结算，不交割标的。到期周期有日、周、月、季，都在 UTC 8点到期。
  3. 买方最大亏损就是权利金，没有强平风险。卖方要缴保证金。2025年8月起，币安向全部用户开放期权卖出，但要先通过适当性测评。
  4. 几个术语。Call 是以行权价买入的权利，Put 是以行权价卖出的权利。权利金是买方付给卖方的价格。IV 是从期权市价反推的波动率。
Payoff · Black-Scholes · 示例

买方亏损有限，卖方亏损无限

  1. 把收益画出来。看涨买方的到期收益，等于结算价减行权价与0取大，再减权利金。示例行权价60000，权利金1662。
  2. 价格低于60000，买方亏掉全部权利金。价格越涨，收益越大，上不封顶。盈亏平衡点在61662。
  3. 卖方正好相反。最多赚1662，涨得越多亏得越多，下不封底。这就是不对称的尾部风险。
  4. 这个1662怎么来的？业界用 Black-Scholes 模型。示例输入：BTC 60000，平值看涨，7天到期，IV 50%，利率0。波动率不可观察，由报价反推的就是 IV。
  5. 标准差是0.5乘以根号下7除以365，约0.0692。平值近似，权利金约等于0.4乘以60000乘以0.0692，约1662。
  6. 这些敏感度叫 Greeks。示例 Delta 约0.51，标的涨100，权利金约涨51。Gamma 在临近到期的平值期权上最大。Theta 为负，买方每天都在付租金。
Money Flow · State · Market Making

期权的资金流

  1. 再看钱怎么走。成交时，权利金立即从买方转给卖方。卖方保证金被冻结，双方都付手续费。
  2. 到期如果是实值，就从卖方保证金里付行权收益给买方，剩余解冻。全是账本内划转，不上链。保证金不够付，业界通常由期权保险基金承担。
  3. 状态机很简单。欧式期权只有一个行权时点，实值自动行权，虚值作废。结算价通常取到期前一段时间的指数均价，防止被操纵。
  4. 期权合约很多，标的乘期限，再乘几十个行权价。单个合约流动性很薄，业界通常依赖指定做市商持续报价。
  5. 调用链上，波动率曲面拟合 IV，发布标记价。做市商双边报价，风控检查卖方保证金和价格带，再挂单撮合。
Writer Margin · 示例公式 · 以官网为准

收 300 权利金，冻结 6,300 保证金

卖出看涨初始保证金 = 标记价 + max(15% × 指数价 − 虚值额, 10% × 指数价)
虚值额 = max(K − 指数价, 0)
示例：K = 66,000 · 指数价 60,000 · 标记价 300 → 虚值额 6,000
15% × 60,000 − 6,000 = 3,000
10% × 60,000 = 6,000 → 取 6,000
初始保证金 = 300 + 6,000 = 6,300
BTC 涨到 80,000 → 卖方赔 14,000
平台：手续费按名义价值比例，设权利金比例上限
做市商：赚价差，在永续或现货对冲 Delta
示例：低波动期卖虚值看涨 → 单日 +20% → 保证金吃光
2018 OptionSellers.com · 公开报道
  1. 卖方要冻结多少保证金？这是参考业界做法的示例公式，币安以官网为准。初始保证金等于标记价，加上两项中较大的一项。
  2. 第一项是15%的指数价减去虚值额，第二项是10%的指数价。看涨的虚值额，是行权价减指数价，与0取大。
  3. 代入示例。卖出1张 BTC 看涨，行权价66000，指数价60000，标记价300。虚值额是6000。
  4. 15%乘以60000，减6000，得3000。10%乘以60000，得6000。两者取大，是6000。
  5. 初始保证金等于300加6000，6300 USDT。只收300权利金，却要冻结6300。因为 BTC 涨到80000时，卖方要赔14000。
  6. 平台赚手续费，业界通常按名义价值比例收，并设权利金比例上限。做市商赚价差，再用永续或现货对冲 Delta。
  7. 失败场景，示例。低波动期大量卖虚值看涨，一次单日20%的上涨，保证金就被吃光。根据公开报道，2018年 OptionSellers.com 卖天然气裸看涨。气价急涨，客户亏光还欠了债。
Risk Limits · 业界通用做法 · 数值以官网为准

从源头控制强平单有多大

限额目的
分层杠杆大仓位多交保证金
单用户最大持仓防一个账户砸穿订单簿
全市场持仓上限新合约、浅市场先设低上限
单笔下单上限防胖手指订单
价格保护带价格不能偏离标记价太远
  1. 最后一段，风险限额。除了分层杠杆，业界通常还有四种限额。持仓上限分单用户和全市场，再加单笔下单上限和价格保护带。具体数值以官网为准。
  2. 分层和强平连在一起。大仓位层级高，MMR 高，强平更早，缓冲更大。部分强平降到低层级后，账户可能恢复安全。
  3. 看一笔开仓的校验。用户要开300万 USDT 名义价值。注意，分层按加上这笔订单之后的仓位算。它落在第4层，最大杠杆20倍。
  4. 杠杆高于20倍，或超过持仓上限，都拒绝。都通过才冻结初始保证金。限额可以热更新。太松，巨鲸强平会耗尽保险基金。太紧，机构会流走。
  5. 失败案例。根据公开报道，2022年 Mango Markets 被攻击。攻击者在很浅的 MNGO 永续上建巨大仓位，同时拉升现货。再用虚高的未实现盈利作抵押，借走协议资金。所以浅市场要有持仓上限。
Summary

记住三件事

  • 组合保证金按最差情景亏损收保证金：示例 12,000 → 300。
  • 期权买方最多亏权利金，卖方亏损无上限：收 300，冻结 6,300。
  • 风险限额从源头控制强平单规模：分层、持仓上限、价格带。

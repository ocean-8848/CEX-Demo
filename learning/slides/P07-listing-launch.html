Listing State Machine · 业界抽象

从申请到下架：一个代币的一生

  1. 先看平台内部，一个代币从申请到下架，是一台状态机。起点是项目方提交申请。
  2. 初审通过，进入尽调。材料不全，或者尽调发现重大风险，直接拒绝。
  3. 尽调完成，交给上币委员会。委员会否决就结束，通过则进入技术接入。
  4. 节点和参数就绪，发布公告。到点开放充值，然后开盘交易。
  5. 上线并不是终点。每个代币都在交易和观察之间，接受周期复审。不达标就加观察标签，指标恢复再移除。
  6. 下架也是流程，先公告，再停止交易，保留提币窗口，最后关闭提币。委员会规则和复审周期没有完整公开，这张图是业界抽象。

  1. 尽调分四条线并行，每条线给出通过、不通过或有条件通过。第一条线看团队，实名背景、过往项目和法律纠纷。匿名无担保或有跑路历史，会被否决。
  2. 第二条线看代码，重点是审计报告，以及增发、冻结、升级权限。合约能无限增发，或者管理员能冻结任意地址，都会被否决。
  3. 第三条线看代币经济。总量、流通量、解锁计划和集中度。示例，前10个地址持有90%，或者首年大量解锁，都很危险。
  4. 第四条线看合规。会不会被认定为证券，是否涉及制裁名单或者隐私币。
  5. 上线之后还有标签。根据币安公开资料，2023年7月，种子标签替代了创新区。带种子标签的代币，波动和风险更高。用户每90天要通过一次风险测验，才能交易带种子或观察标签的代币。
  6. 观察标签，标记可能不再满足上币标准的代币。它不等于自动下架，但会被更频繁地复审。公开报道显示，标记公告发布当天，代币价格常大幅下跌。

技术接入：一串按时间表触发的开关

  1. 委员会通过之后，进入技术接入。运营后台先在上币服务里，创建资产 XYZ 和它的 USDT 交易对。
  2. 上币服务向扫链服务注册合约地址和确认数阈值。再让托管适配层生成充值地址池，配置热钱包。
  3. 然后把交易对参数写进订单服务。撮合引擎创建一个空订单簿，状态是预交易。
  4. 举个示例，参考价0.0523 USDT。tickSize 设为0.0001，stepSize 是1。最小下单额5 USDT。一个 tick，业界经验约为价格的0.01%到0.1%。
  5. 到点开放充值，再开启集合竞价或仅限价阶段。产生开盘价后，切换为连续交易。开盘之后才开放提币。
  6. 每个开关都有独立的回滚按钮。扫链要先跑通一次小额充值到入账，才能对外开放。转账扣税这类代币，扫到的金额和到账不一致，账本会出现差额。

开盘即暴跌 · 业界

空投获得者第一分钟集中卖出，做市买单不足，价格单边下跌

低流通、高 FDV · 业界

流通量只占 10% · 示例，后续每月解锁持续带来抛压，2024 年起社区批评很多
  1. 开盘那一刻，卖单从哪来？三类人。空投和挖矿的获得者，充值进来的早期持有人，还有开盘前挂双边单的做市商。
  2. 一个出错点是，充值通道开放太晚。卖盘很薄，少量买单就把开盘价推高，然后迅速回落。
  3. 所以业界有几种开盘保护。第一种是集合竞价。开盘前几分钟只收单不成交，到点按成交量最大的原则，算出单一开盘价。
  4. 第二种是仅限价阶段，前几分钟禁止市价单。第三种是价格带保护，拒绝偏离参考价太多的订单。币安 API 有一个按买卖方向的百分比价格过滤器。
  5. 开盘后还常见两种失败。一是空投获得者第一分钟集中卖出，做市买单不足，价格单边下跌。二是低流通、高完全稀释估值。示例里流通只占10%，后续每月解锁持续带来抛压。

  1. 平台从上币得到三种收益。第一是手续费。新币首日成交量往往很高，成交量乘以费率，就是收入。
  2. 第二是流量，用户为参与活动而注册和充值。第三是 BNB 需求，发行活动都以 BNB 持仓为门槛。
  3. 再说上币费争议，我们只陈述公开报道。2024年10月31日，一家加密投资机构的创始人在社交媒体发文。文中称，币安向某项目索要约15%的代币供应量，作为上币条件。
  4. 币安联合创始人何一公开否认。她表示，币安不收取代币比例或固定金额。
  5. 公开报道里，币安自2018年起的政策是，上币费用透明，100%捐给慈善。金额由项目方提出，平台不规定最低额。
  6. 争议的核心，不是有没有明面费用。而是空投额度、营销额度和做市安排，是否构成隐性成本。这些合同细节，外部无法验证。
Launchpad · Measurement

计算期：每小时快照，取平均

计算期每小时快照 BNB 余额
认购期承诺上限 = 平均持仓
分配期扣款 · 发币 · 退款
  1. 第一个分发渠道是 Launchpad，用 BNB 认购新币。公开报道显示，它分计算期、认购期、分配期三个阶段。
  2. 计算期里，系统每小时快照一次你的 BNB 余额。公开报道的典型值是连续6天，最后取平均，作为认购时的承诺上限。
  3. 临时充入大量 BNB，能不能拉高上限？看示例。6天就是144次快照，你平时持有1个 BNB。
  4. 最后6小时，你临时充入100个。于是138个小时余额是1，6个小时是101。
  5. 平均持仓是138加606，除以144。744除以144，约等于5.17个。
  6. 临时充入100个，只换来4.17个额外上限。而且计算期一结束，上限就固定了，认购期再充值也没用。
Launchpad · Commit → Calculate → Distribute

超额认购：大部分 BNB 原路退回

  1. 认购期，你提交 BNB 承诺。承诺只冻结，不扣款，用的是账本的冻结分录。
  2. 示例，发售1000万个 NEW，发行价0.02 USDT，BNB 价格600。募资目标20万 USDT，约333.33个 BNB。
  3. 全网承诺了100万个 BNB，超额认购约3000倍。你承诺10个 BNB，份额是0.001%。
  4. 你的分配量，是0.001%乘以1000万，等于100个 NEW。扣款是100乘以0.02，再除以600，约0.003333个 BNB。
  5. 剩下的9.996667个 BNB 原路退回。扣款、发币、退款必须在同一个账本事务里。否则会出现代币到账、BNB 没退的中间状态。
  6. 如果单人分配量有硬顶，超出部分按比例分给其他用户。公开报道里，2023年7月某次认购，承诺总值约24亿美元，募资只有数百万美元。
  7. 用户的风险是破发，开盘价低于发行价。还有人用多个 KYC 账户拆分承诺，绕过单人硬顶。防线是 KYC 唯一性和设备关联风控。
Launchpool · Farming

Launchpool：锁仓挖新币

  1. 第二个渠道，Launchpool，质押挖新币。用户把 BNB 或指定资产锁进池子，报道里出现过 FDUSD 和 USDC 池。本金不交给项目方，可随时赎回，以活动规则为准。
  2. 奖励按小时发放。你的小时均值除以全池小时均值，再乘以每小时奖励量。公开报道显示，每个池还有单人每小时上限。
  3. 看示例。全池200万个 BNB，你有10个，每小时奖励5万个 NEW。你的份额是0.0005%，每小时拿到0.25个 NEW。
  4. 一天是6个 NEW。假设开盘价0.5 USDT，就是3 USDT。等价年化等于3乘以365，除以10乘以600，得到18.25%。
  5. 现在后来者涌入，全池涨到400万。你什么都没做，份额减半，年化降到约9.13%。
  6. 涨到800万，年化只剩约4.56%。还要注意，年化依赖开盘价假设。开盘价减半，年化同样减半。
Launchpool · Hourly Snapshots

一小时内多次随机快照

  1. 根据公开报道，系统每小时对个人和全池余额做多次快照，取小时平均。一直锁着10个，均值就是10。
  2. 快照时刻是随机的。整点前存入、整点后取出的套路，几乎拿不到奖励。
  3. 再看示例。有人只在这个小时的最后15分钟，锁入10个 BNB。小时均值约2.5个，他只拿到四分之一的奖励。
  4. 奖励由批量记账发放，从奖励账户转到用户现货。失败要幂等重试，幂等键是活动 ID、小时和用户 ID。
  5. 风险在开盘时。大量用户同时卖出奖励，价格单边下跌。挖矿收益，也可能远小于 BNB 自身的价格波动。

  1. 第三类是空投。先看 HODLer Airdrops。只要把 BNB 放进 Simple Earn。活期定期都算，链上收益产品也计入。
  2. 它的关键词是回溯。系统回看公告前的一段历史窗口，每小时多次快照取平均。公告发出时，窗口已经结束，临时买入没有用。
  3. 份额有上限，单人不超过全池的4%。示例，全池均值3000万个 BNB，你有30个，空投总量1500万个 NEW。份额是0.0001%，你拿到15个。
  4. 再看 Megadrop。锁定 BNB 定期产品，再在 Binance Web3 钱包完成任务。总分等于锁仓分乘以任务倍数，再加任务奖励分。
  5. 示例。锁仓分100，倍数1.5，奖励分20，总分170。全网总分1000万，空投总量2000万个 NEW，你得到340个。
  6. 最后是 Binance Alpha，在钱包里交易还没上现货的早期代币。积分按15天滚动窗口计算，按门槛领取空投，领取会消耗积分。
  7. 风险是，Alpha 代币没走完现货上币的全部尽调，容易被误解为币安背书。还有人对倒刷积分，平台用门槛调整和异常检测应对。
Flywheel

飞轮：BNB 需求如何被拉动

  1. 把这些活动串起来，就是一个飞轮。起点是新币活动，参与门槛是持有 BNB。
  2. 用户买入并长期持有 BNB。需求上升，生态吸引力上升，更多项目来币安首发，又带来更多活动。
  3. 闲置的 BNB 还会放进 Simple Earn，平台的理财规模也跟着上升。
  4. 但还有负循环。奖励在开盘时被卖出，如果新币持续破发，用户觉得挖到的币不值钱，参与意愿就会下降。
  5. 快照取平均，奖励长期持有者而不是临时资金，让 BNB 需求更粘。但飞轮强度依赖新币的二级市场表现，平台无法控制。

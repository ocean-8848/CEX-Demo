Margin · 截至 2026 年币安公开资料

杠杆账户：全仓、逐仓与保证金水平

全仓：账户内全部资产
共同担保全部负债
逐仓：每个交易对一个账户
亏损只限于这个账户
ML 越低越危险，1.1 强平
合约保证金率越高越危险
ML = 总资产价值 ÷ (总负债 + 未还利息)
全仓经典正常追保 · 禁止新借强平
3x> 1.31.1 – 1.3≤ 1.1
5x> 1.161.1 – 1.16≤ 1.1
逐仓：ML 低于 2 禁止转出 · 强平线随杠杆档变化，本集示例用 1.1 · 以官网为准
  1. 先看杠杆账户。根据币安公开资料，它有两种模式。全仓杠杆，账户里全部资产共同担保全部负债。逐仓杠杆，每个交易对一个独立账户，亏损只限于这个账户。
  2. 衡量风险的指标叫保证金水平，简称 ML。它等于总资产价值，除以总负债加未还利息。意思是资产能覆盖几倍负债。
  3. 以全仓经典模式的3倍档为例。ML 大于1.3算正常。降到1.3及以下进入追保，不能再借新款。降到1.1及以下，停止交易并强平。5倍档的追保线是1.16，强平线同样是1.1。
  4. 注意方向。保证金水平越低越危险。主线讲过的合约保证金率，是越高越危险。两个指标别搞反。
Money Flow · 示例数字

一笔杠杆买入：钱怎么走

  1. 来看一笔具体的杠杆买入，数字都是示例。第一步，用户把1000 USDT 本金，从现货账户划进杠杆账户。
  2. 第二步，从借贷资金池借出2000 USDT。资金池里的钱，主要来自理财用户的活期存款。这两笔都是账本内划转，不上链。
  3. 第三步，用3000 USDT 在50000的价格，买入0.06个 BTC。杠杆买入走的是同一个现货撮合引擎。买到的是真实的币，不是合约头寸。
  4. 第四步，按小时计息，利息先记进应收利息账户。示例年化8%，2000乘8%再除以8760，每小时约0.0183。持有30天，大约13.15 USDT。
  5. 第五步，还本付息。利息一部分分给理财用户，剩下的利差进入平台收入。
  6. 服务层面，业界通常这样拆。借款前，风控检查可借额度和 ML。借款、计息、还款都是账本分录，借款单号做幂等键，网络重试也不会借两次。
Margin Level · 示例：本金 1,000 · 借 2,000 · 0.06 BTC

价格下跌，ML 一路走向 1.1

  1. 现在算三条价格线。示例仓位是：本金1000，借2000，持有0.06个 BTC。开仓时总资产3000，负债2000，ML 等于1.5。
  2. 忽略利息和折算率，总资产就是持币数量乘以价格。追保价等于1.3乘以负债，再除以持币数量。1.3乘2000除以0.06，约43333.33，下跌约13.3%。
  3. 强平价是1.1乘2000除以0.06，约36666.67，下跌约26.7%。
  4. 再往下是破产价，资产正好等于负债。2000除以0.06，约33333.33。强平线1.1和破产线1.0之间，留了10%的缓冲，给系统卖出抵押物。
  5. 如果价格跳空呢？示例里，价格从40000直接跳到30000。0.06个 BTC 只值1800，负债是2000。缺口200 USDT，就成了坏账。
State Machine

杠杆账户的六个状态

  1. 把这些线串成状态机。用户划入本金，状态是无负债。一借币，进入正常状态。还清借款，又回到无负债。
  2. ML 降到1.3及以下，进入追保。根据币安公开规则，追保时不能新借款，这是第一道闸。用户补保证金、还款，或者价格回升，就回到正常。
  3. ML 降到1.1及以下，进入强平中。系统撤掉挂单，卖出资产还债。足额还清，就是已结清。
  4. 再看这条红色虚线。价格跳空时，账户会从正常直接进入强平中，用户没有追保窗口。卖光资产还不够，就进入坏账。业界通常由平台兜底，不转嫁给理财用户。
Binance Loans · 截至 2026 年公开资料 + 示例

质押借币：盯住抵押率 LTV

质押一种币，借出另一种币
每个币对独立仓位 ≈ 逐仓
活期：利息每分钟累计
质押物自动申购活期理财
LTV = (借款 + 未还利息)
　　　÷ 质押物价值
  1. 第二个产品，质押借币 Binance Loans。根据币安公开资料，用户质押一种币，借出另一种币。每个币对是一个独立仓位，相当于逐仓。
  2. 活期借贷随借随还，利息每分钟累计，利率每分钟更新。还有一个设计：质押物会自动申购活期理财，借款期间继续拿收益。
  3. 衡量风险的指标是抵押率 LTV。它等于借款本金加未还利息，除以质押物价值。本集示例用三条线：初始65%，追保85%，强平91%。
  4. 举个示例。质押1个 BTC，指数价60000。借出39000 USDT，LTV 正好65%。按示例年化6%，30天利息约192.33。
  5. 价格跌到45882.35，LTV 到85%，触发追保。这是39000除以0.85算出来的，下跌约23.5%。
  6. 跌到42857.14，LTV 到91%，触发强平，下跌约28.6%。对单一仓位，ML 等于 LTV 的倒数。LTV 91%约等于 ML 1.099，两条强平线几乎一样。
Loans Money Flow · 业界通用做法

质押物：既是抵押，又是存款

  1. 再看资金流。和杠杆账户不同，借到的 USDT 直接进入现货账户，用户可以自由使用。质押物冻结在一个独立子账户里。
  2. 注意质押物的双重身份。它被冻结作抵押，同时又在理财池里，算作资金池的存款。业界通常要区分可赎回余额和已质押余额。
  3. 强平的调用顺序是这样的。强平引擎按指数价重算 LTV。达到91%，借贷服务先从理财里赎回质押物，再卖出还债。赎回受限，强平就会变慢。
  4. 业界通常只卖够还债的部分。扣掉示例的清算费，剩下的质押物退回用户。
  5. 风险在哪？一是强平螺旋。很多人用同一种币质押，币价下跌，强平卖单集中出现，价格继续下跌，又触发更多强平。
  6. 二是期限错配。根据公开报道，2022年 Celsius 把存款拿去做高风险出借和质押。挤兑之后，它暂停提现并破产。
VIP Loan · 截至 2026 年币安公开资料

VIP 借贷：人在环中

Binance LoansVIP 借贷
准入KYC 用户VIP 机构 · 首笔 ≥ 50 万美元
质押物冻结在子账户留在现货钱包，可交易
资产范围单一币对跨账户聚合
计息与费用活期每分钟累计活期按小时 · 定期 30/60 天按日 · 逾期 3 倍 · 清算费 2%
  1. 第三个产品，VIP 借贷，面向机构。根据币安公开资料，它只对 VIP 用户开放，首笔借款不低于50万美元。
  2. 它和 Binance Loans 有两点关键不同。第一，质押物留在现货钱包，只要 LTV 和风险率达标，还能自由交易。第二，可以跨账户聚合资产。
  3. 计息规则也公开了。活期按小时计算和累计。定期有30天和60天，按日计息。逾期按三倍日利率计息，触发强平收2%清算费。
  4. 它还支持延迟强平和定制化追保。状态机多了一个宽限期。追保以后先由客户经理沟通，宽限期内补仓就回到正常。宽限期结束，才走系统强平。
  5. 体验更好，代价是平台在跳空行情里多担风险。根据公开报道，2022年三箭资本违约。多家机构借贷平台对它放了大额低抵押贷款，最后形成巨额坏账。教训是，信用借贷要有抵押、有集中度上限、有实时风险视图。
Lending Pool · Kink Model · 业界通用做法 + 示例参数

钱从哪来，利率怎么定

  1. 现在回答开头的问题：钱从哪来。根据币安公开资料，理财资金用于杠杆借贷、流动性提供和机构借贷，由抵押物担保。业界通常再用平台自有资金作补充。
  2. 关键变量是利用率 U，等于已借出除以总存款。U 越高，闲置余额越少。而存款人赎回，只能用闲置余额来支付。
  3. 利率怎么定？币安内部模型没有公开。业界通用做法来自链上借贷协议，叫拐点利率模型。U 在拐点以下，利率缓慢上升。超过拐点，斜率突然变陡。
  4. 代入示例参数。基础利率1%，斜率一6%，拐点80%。斜率二60%，平台抽成10%。U 等于70%时，借款利率6.25%，存款利率约3.94%。
  5. U 到拐点80%，借款利率7%，存款利率5.04%。
  6. U 到95%，借款利率跳到52%，存款利率约44.46%。这就是开头那个跳变。
Bank Run · 示例

当铺的大水缸

  1. 打个比方。资金池像当铺后面的大水缸。存款人往缸里倒水，借款人拿抵押物来舀水。缸快见底时，舀一瓢水的价格会突然翻几倍。
  2. 来推演一次挤兑，数字是示例。资金池存款1亿 USDT，借出7000万，U 是70%。
  3. 存款人取走2000万。存款剩8000万，U 升到87.5%。借款利率等于7%加上60%乘0.375，也就是29.5%。
  4. 再取走500万。存款剩7500万，U 约93.3%，借款利率约47%。闲置只剩500万，更大的赎回请求，无法立即满足。
  5. 高利率本来是负反馈：借款人还款，新存款进来，U 回落。但比喻在这里不成立。真实借款人如果被锁在亏损仓位里，利率再高也还不了款，回路就失效了。
Net Interest Margin · 示例：U = 70% · D = 1 亿

平台的利差：借款利息 × 平台抽成

平台利息收入 = R × B − S × D = R × B × 平台抽成
  1. 平台从借贷里怎么赚钱？利差公式是：借款利率乘以已借出，减去存款利率乘以总存款。化简后，等于借款利率乘已借出，再乘平台抽成。
  2. 用 U 等于70%、存款1亿来算。借款人每年付6.25%乘7000万，等于437.5万。
  3. 存款人每年拿3.94%乘1亿，约394万。平台留下约43.75万，正好是437.5万的10%。
  4. 存款利率比借款利率低很多，不等于平台克扣。存款里只有 U 的比例被借出，闲置部分不产生利息。另外，平台还收杠杆交易手续费，以及强平清算费。
Liquidation → Bad Debt · 业界通用做法

强平到坏账：谁来兜底

示例 · 负债 2,000 · 0.06 BTC强平成交价卖出所得还债后
正常强平36,6002,196+196 退回用户
跳空32,0001,920−80 坏账
  1. 最后看最坏情况。指数价下跌，ML 到1.1，或者 LTV 到强平线。系统先撤销账户挂单，再卖出抵押物。
  2. 卖出所得够还负债加利息，扣掉清算费，剩下的退回用户。示例，强平成交价36600，卖得2196，还掉2000后剩196。
  3. 不够还，差额就是坏账。示例，跳空到32000才成交，卖得1920，缺口80 USDT。
  4. 坏账谁来补？业界通常先用杠杆保险基金，不够再由平台自有资金核销。杠杆借贷没有合约那样的自动减仓，最终兜底方是平台自己。
  5. 估价也会出事。根据公开报道，2025年10月10日，三种抵押资产在币安的价格短时偏离。币安称向受影响的合约、杠杆、借贷用户补偿约2.83亿美元。教训是，抵押物估价必须引用多个外部来源。
本集小结

记住三件事

  • ML 越低越危险，LTV 越高越危险；单一仓位里 ML = 1 / LTV。
  • 借出的钱来自理财存款；拐点利率是负反馈，借款人被锁仓时失效。
  • 平台赚利差和清算费；缓冲被跳空打穿，最终由平台兜底。

  1. 小结三点。第一，杠杆账户看保证金水平 ML，越低越危险。质押借币看抵押率 LTV，越高越危险。单一仓位里，两者互为倒数。
  2. 第二，借出去的钱来自理财存款。拐点利率用高利率劝退借款人、吸引存款人。但借款人被锁仓时，这个回路会失效。
  3. 第三，平台赚的是利差和清算费。强平线和破产线之间的缓冲，用来防坏账。跳空打穿缓冲，最后由平台兜底。

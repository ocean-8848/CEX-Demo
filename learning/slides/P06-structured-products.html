  1. 双币投资的页面上，经常写着年化36.5%这样的数字。示例，用1000 USDT 低买 BTC，目标价95000，期限7天。宣传语说，无论涨跌都赚利息。
  2. 可是如果到期时 BTC 跌到85000，你拿回的是0.0106个 BTC。按市价只值901 USDT，本金亏了99。
  3. 利息确实拿到了，亏损从哪来？这一集我们拆开它，双币投资等于一笔存款，加上你卖出的一份期权。先说明，本集内容不构成投资建议。双币投资不保本，数字除公开资料外都是示例。

  1. 根据币安公开资料，双币投资有两个方向。低买，投入 USDT，目标价低于当前价。到期价小于等于目标价，你拿回 BTC，否则拿回 USDT 本息。
  2. 高卖，投入 BTC，目标价高于当前价。到期价大于等于目标价，你拿回 USDT，否则拿回 BTC 本息。
  3. 产品规则有几条。申购后 APR 锁定，结算时间是到期日 UTC 8点。结算价是到期前一段时间的指数均价。业界通常取7点半到8点，币安口径以官网为准。
  4. 申购截止早于结算时间，业界通常提前24小时。一般不支持提前赎回。注意，两种结果都有收益，区别只是拿回哪种币。以投入币种的价值算，你可能亏损。
Worked Example · 示例

本金 1,000 USDT · 目标价 95,000 · 7 天 · APR 36.5%

  1. 先写公式。期限收益率 y，等于 APR 乘以天数，除以365。低买时，到期价高于目标价，拿回本金乘以1加 y 的 USDT。否则把同样的本息除以目标价，换成 BTC。
  2. 代入示例。本金1000 USDT，当前价100000，目标价95000。期限7天，APR 36.5%。y 等于36.5%乘7除以365，就是0.7%。本息1007 USDT。
  3. 期权数量 N，等于1007除以95000，约0.0106个 BTC。
  4. 情形 A，到期价98000，高于目标价。拿回1007 USDT，赚7块。一直拿着 USDT 是1000，今天直接买0.01个 BTC 只值980。
  5. 情形 B，到期价正好95000。拿回0.0106个 BTC，折算还是1007。
  6. 情形 C，到期价85000。0.0106个 BTC 只值901，亏99，也就是9.9%。你按95000接到了只值85000的 BTC。但它比今天直接买多出51。所以低买适合本来就想在95000买 BTC 的人。
Decomposition · Cash-Secured Put

双币投资的到期价值

  1. 现在把所有结果都换算成到期时的 USDT 价值，画成一条曲线。横轴是到期价。到期价高于95000，是一条水平线，1007。
  2. 到期价低于95000，拿回的是0.0106个 BTC，价值随价格线性下跌。整条曲线像一个折角。
  3. 再画两条线。第一条是存款，到期1007 USDT，一条水平线。第二条是卖出 N 份看跌期权的赔付，价格低于目标价时，每跌1块赔 N 块。
  4. 把两条线相加，结果和双币投资的曲线完全重合。所以低买就等于现金担保卖看跌，业界叫 Cash-Secured Put。
  5. 验证情形 C。存款1007，减去期权赔付。赔付是0.0106乘以95000减85000，约106。1007减106，得到901，和直接结算的结果一样。
  6. 高卖也一样。它等于持有 BTC，再卖出同样数量的看涨期权，叫备兑看涨。价格涨过目标价，上涨被换成固定的 USDT，你错过了上涨。
Money Flow · 对冲细节币安未公开

本金不出平台，期权卖给了交易台

  1. 钱是怎么流的？申购时，1000 USDT 被冻结，划入双币持仓。本金不出平台，账本上记成对用户的负债。
  2. 这笔持仓，等价于你把一份看跌期权，卖给了平台的期权交易台。
  3. 交易台在外部市场买入同样的期权，或者用永续合约做 Delta 对冲。这是业界通用做法，币安的对冲细节没有公开。示例里，市场给这份期权的价格是9.53 USDT。
  4. 交易台付给你7块收益，留下2.53作为平台收入。你看不到9.53这个市场价。
  5. 到期时，价格高于目标价，你收到1007 USDT。否则收到0.0106个 BTC。
Black-Scholes · r = 0 · IV 50% · 示例

公允期权费 9.53，你拿到 7.00

  1. 平台抽多少？用 Black-Scholes 给这份看跌期权定价，示例利率0，IV 50%。1个 BTC 名义、行权价95000、7天的看跌期权，公允价格约899.12 USDT。
  2. 你卖出0.0106份，公允期权费约9.53 USDT。平台付给你7块，差价约2.53，约占公允期权费的27%。
  3. 换成年化来看，公允 APR 约49.8%，你拿到36.5%，差了13.3个百分点。这就是平台的抽成，它藏在报价里，用户看不到。
Short Volatility · 示例

APR 最高的时候，往往最危险

  1. 为什么 APR 有时高有时低？因为期权价格随隐含波动率上升。同样的目标价和期限，示例中 IV 40%时，公允 APR 约28.5%。
  2. IV 50%时约49.8%，IV 60%时升到约73.9%。
  3. 所以每次申购，你都是在卖出波动率。平静时赚小钱，暴跌时亏大钱。页面 APR 最高的时候，通常正是市场恐慌、IV 最高的时候，下跌风险也最大。
  4. 还有一条规律。目标价越接近当前价，期权越值钱，APR 越高，被换成另一种币的概率也越高。
State · Call Chain · 组件名为示例

报价、申购、对冲、结算

  1. 系统里怎么实现？主线没有结构化产品服务，我们新增几个示例组件。用户查看报价时，产品服务找定价引擎，读取 IV 和利率。算出公允 APR 49.8%，扣掉抽成，报价36.5%。
  2. 报价有效期示例是10秒。报价和申购分两步，防止用户拿旧报价套利。行情一变，旧报价就作废。
  3. 首次申购要先过适当性测评。通过后，账本冻结1000 USDT，划入双币持仓。然后通知对冲引擎，新增0.0106 BTC 的空头看跌敞口。
  4. 对冲引擎按净敞口对冲。很多用户的低买和高卖，可以相互抵消一部分。剩下的再去外部市场买期权，或者做 Delta 对冲。
  5. 到期日 UTC 8点，读取结算价，记结算分录，返还 USDT 或发放 BTC。发 BTC 时，对手方是平台的对冲账户。结算价不能取本所插针价，要用多交易所指数的时间均价。

  1. 用户承担三种风险。低买被行权，以高于市价的价格买入 BTC。高卖被行权，以低于市价的价格卖出，错过上涨。还有流动性锁定，期限内不能赎回，也不能止损。
  2. 平台也有风险。对冲失败，外部期权市场深度不够，就用永续做 Delta 对冲，再给单币种设总额度。跳空风险，价格瞬间跳过目标价，对冲来不及调。
  3. 还有对手方风险、定价模型错误和结算价操纵。对应的兜底是分散对冲场所，报价上下限，多交易所指数加30分钟均价。
  4. 所以平台要做适当性评估。业界通常先让用户填风险测评问卷，定风险等级。产品也有等级，用户不能申购高于自己等级的产品。申购页强制展示非保本和最坏情形，部分地区直接下线。
Failure Cases

单日暴跌：所有低买一起被行权

  1. 看几个失败场景。情景示例，BTC 一天下跌20%。所有目标价在区间内的低买订单，全部被行权。用户按目标价接货，账面立刻亏损。
  2. 更麻烦的是，这时新报价的 APR 暴涨，吸引更多用户继续接飞刀。
  3. 根据公开报道，2025年10月10日，全市场单日强平超过190亿美元。期权和永续市场的流动性同时枯竭，对冲引擎在这种时刻最难调整仓位。
  4. 业界最常见的投诉，是把它误解为保本。用户只看到无论涨跌都有收益，忽略了拿回的币种会变。这正是适当性评估和信息披露要解决的问题。
Shark Fin · 示例条款 · 币安同类产品以官网为准

先上升，再断崖：鲨鱼鳍

  1. 最后看反方向的产品，鲨鱼鳍。它是保本型结构化产品，OKX、Bybit 等交易所公开提供。示例条款：本金10000 USDT，到期全额返还，期限14天，当前价100000。
  2. 到期价在100000到110000之间，APR 从2%线性升到20%。低于下限，拿保底2%。
  3. 但期限内只要曾经突破110000，就敲出，APR 回落到2%。收益曲线先上升再断崖，像鲨鱼的背鳍，所以叫这个名字。
  4. 敲出判断必须用指数价格。示例，本所插针到110050，指数没到110000。如果误用本所价格，用户收益就被错误降为保底。修复方式是只用指数，并保留价格证据。
Deposit + Bull Call Spread + Knock-Out · 示例

利息预算买期权

  1. 拆开看，鲨鱼鳍等于存款，加上买入看涨价差，再加敲出条款。这次用户是期权的买方，本金不承担价格风险。平台是买方，对冲压力也小于双币投资。
  2. 钱从哪来？平台把本金用于出借或理财，示例年化5%，14天赚约19.18 USDT。保底2%要付7.67。剩下11.51，就是买期权的预算。
  3. 看涨价差是买入100000看涨，卖出110000看涨。额外收益上限是10000乘18%，乘14除以365，约69.04。期权数量约0.0069个 BTC。
  4. 用 Black-Scholes 算，示例 IV 50%。普通看涨价差约20.75 USDT，超出预算。加上敲出条款，期权在敲出时作废，就便宜下来，压进预算。所以断崖是设计的必然，不是巧合。
  5. 风险也要看清。保本依赖平台信用，平台破产时承诺无效。大多数情形只拿保底，可能低于活期。利率越低，预算越少，收益上限也越低。
Summary

记住三件事

  • 双币投资 = 存款 + 卖出期权：低买 = 现金担保卖看跌，高卖 = 备兑看涨。
  • 高年化是卖出波动率的报酬，平台从公允期权费里抽成。
  • 鲨鱼鳍用利息预算买期权，敲出让期权变便宜，也造出断崖。

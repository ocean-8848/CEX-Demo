永续合约：资金费率与标记价格

问题一

永续合约不到期，价格凭什么不跑偏？

问题二

一笔大单砸出插针，仓位会被误伤强平吗？
仅讲系统设计，不构成投资建议 · 杠杆会放大亏损 · 除公开资料外数字均为示例
  1. 交割合约有到期日，到期那天按指数价格结算，价格自然会回到现货。可是永续合约没有到期日。那它的价格，凭什么不跑偏？
  2. 还有第二个问题。如果有人用一笔大单，把合约价格瞬间砸下去，你的仓位会不会被误伤强平？
  3. 这一集就回答这两个问题，答案是资金费率和标记价格。先说明，本集只讲系统设计，不构成投资建议。杠杆会放大亏损，除了公开资料，数字都是示例。

  1. 先把四种交易方式摆在一起。现货，你持有真实的币，没有杠杆，也不能做空。
  2. 杠杆交易，是借钱或借币，买卖真实的币。示例杠杆是3到10倍，成本多了一项借币利息。
  3. 交割合约，你持有的是一份合约，不是币。它有到期日，比如季度合约，到期按指数价格结算。
  4. 永续合约也是合约，但没有到期日。它多了一项成本，叫资金费。根据币安公开资料，部分 U 本位合约最高125倍杠杆。
  5. 从左往右，每一步都改进了上一步的一个不便。想放大收益，用杠杆。只要价格敞口，用合约。不想每个季度换月，用永续。代价是系统越来越复杂。
Why Funding

交割合约：到期自然收敛

  1. 先看交割合约。合约价可以高于现货，也可以低于现货。但到期那天，系统强制按指数价结算。所以越接近到期，两条线越靠近，最后重合。
  2. 永续合约去掉了到期日，也就失去了这种自然收敛。如果什么都不做，合约价可以一直偏离现货。
  3. 所以永续必须引入一个新机制，叫资金费率。打个比方，它像一根橡皮筋，一头拴着现货，一头拴着合约。跑得越远，拉力越大。
  4. 但比喻有不成立的地方。橡皮筋是连续用力的，资金费率不是。它每个周期才结算一次。两次结算之间，合约价可以偏离很远。
Funding Rate · 币安 U 本位公开公式
F = P + clamp( I − P, −0.05%, +0.05% )
  1. 根据币安公开资料，U 本位永续的资金费率公式是这样的。F 等于 P，加上一个修正项。修正项是 I 减 P，并且被限制在正负0.05%之间。
  2. P 是溢价指数，衡量合约价格比指数价格高多少。它用冲击买价和冲击卖价来算，每个周期内多次采样，再取平均。
  3. I 是利率，默认每8小时0.01%。它代表 USDT 和 BTC 的借贷利差。
  4. 举个示例。P 等于0.03%。I 减 P 等于负0.02%，在正负0.05%之内，不用截断。F 等于0.03%减0.02%，结果正好是0.01%。
  5. 再算一个。P 等于0.2%。I 减 P 是负0.19%，超出范围，被截到负0.05%。F 等于0.2%减0.05%，也就是0.15%。
  6. 推一下就知道。只要 P 落在负0.04%到0.06%之间，F 就恰好等于0.01%。这就是市场平静时，资金费率常年是0.01%的原因。资金费率另有上下限，以官网为准。
Funding Payment

资金费：多空之间转移，交易所不收

  1. 资金费多久结算一次？根据币安公开资料，默认每8小时一次，在 UTC 的0点、8点和16点。部分合约是4小时或1小时。行情剧烈时，币安还可以缩短周期。
  2. 资金费等于持仓名义价值乘以资金费率。名义价值等于标记价格乘以仓位数量。举个示例，你持有1个 BTC 多单，标记价格50000，资金费率0.01%。
  3. 费率是正的，多头付钱给空头。50000乘以0.01%，你要付5 USDT。持有同样空单的人，收到5 USDT。
  4. 如果费率是负的，方向反过来，空头付钱给多头。
  5. 注意两点。第一，交易所不收这笔钱，它只在多空之间转移。第二，只有在结算时刻持仓的人，才付或收资金费。
Negative Feedback

资金费率构成一个负反馈回路

  1. 把资金费率放回市场里看，它构成一个负反馈回路。合约价高于指数价，溢价指数为正，资金费率也就为正。
  2. 费率为正，多头付钱给空头。持多的成本上升，持空反而有收益。
  3. 于是部分多头平仓，套利者也进场开空。
  4. 套利者是关键角色。他们在现货买入，在合约做空，一边赚资金费，一边把价差压回去。合约价因此回到指数价附近。
  5. 价格偏离越大，拉回的力越大。不过别忘了刚才的局限：资金费每个周期才结算一次，不是实时生效。

标记价格 = 中位数( 价格1, 价格2, 合约最新价 ) 价格1 = 指数价格 × (1 + 上次资金费率 × 距下次结算时间 / 资金费率周期) 价格2 = 指数价格 + 移动平均基差(30 秒)
  1. 第三段，三种价格。最新价，是本合约最新一笔成交价，用来显示行情和下单参考。
  2. 指数价格，是多个现货交易所价格的加权平均。它用于计算资金费率，也是标记价格的基础。
  3. 标记价格，由指数价格和合约价格推导出来。它用来计算未实现盈亏，以及判断强平。这一点最关键。
  4. 根据币安公开资料，标记价格取三个数的中位数。价格1，是指数价格乘以一个资金费率修正。价格2，是指数价格加上30秒的移动平均基差。第三个，是合约最新价。
Index Price Guard

指数价格：偏离中位数超过 3% 就截断

  1. 指数价格本身也有保护。来看一个示例，5家现货交易所的报价。其中4家在50000附近，E 交易所出了故障，报出46000。
  2. 根据币安公开资料，某个报价偏离全部报价的中位数超过3%时，就会被截断。截断范围是中位数的0.97倍到1.03倍。
  3. 中位数是50000，所以 E 的报价被截到48500。单个交易所出故障，对指数的影响就被限制住了。
Wick vs Mark Price

插针：按最新价会强平，按标记价格不会

示例仓位：10x 多单
开仓价 50,000
强平价 45,180.72
价格147,860
价格247,800
最新价44,600
中位数 = 47,800
  1. 举个示例。你开了一个10倍多单，开仓价50000。按下一集要推导的公式，强平价大约是45180.72。之后价格慢慢走低到48000附近。
  2. 某一刻，合约订单簿很薄。一笔大额市价卖单，把最新价瞬间砸到44600，然后又弹了回来。这就是插针。
  3. 如果系统用最新价判断强平，插针那一瞬间，价格穿过了强平线，你的仓位会被强平。可价格几秒后就回来了。
  4. 现在加上标记价格。插针那一刻，标记价格只下探到47800左右，离强平线很远。仓位安然无恙。
  5. 为什么？标记价格取三个数的中位数。价格1和价格2都锚定指数价格，几乎不动。最新价单独被打穿，排在最低，中位数不会选它。
  6. 但标记价格防的是假波动，不防真波动。如果全部现货交易所同时下跌，指数价格跟着跌，标记价格照样会穿过强平线。

保证金资产的估价，也要看外部来源

> 190 亿美元
约 75% 强平发生在偏离之前 · 币安称
补偿 ≈ 2.83 亿美元
教训：保证金估价要引用多个外部来源
  1. 来看一个真实案例。根据公开报道，2025年10月10日，美国宣布对中国进口商品加征100%关税。加密市场24小时内强平超过190亿美元，是史上最大单日强平。多家交易所触发了 ADL。
  2. 在币安，USDe、WBETH、BNSOL 三种资产出现了指数偏离。时间是 UTC 21点36分到22点16分。USDe 在币安一度跌破0.66美元，而其他场所基本维持锚定。
  3. 问题出在哪里？用这些资产做保证金的用户，保证金的估价跟着本所的价格被砸穿，于是被强平。
  4. 币安称，约75%的强平发生在偏离之前。币安在24小时内，向受影响的合约、杠杆、借贷用户补偿约2.83亿美元。
  5. 教训是，保证金资产的估价，和标记价格一样，必须引用多个外部来源。只看本所订单簿，流动性枯竭时就会被砸穿，引发不公正的连锁强平。
Misconceptions

四个常见误区

✕资金费是交易所收的✓ 只在多空之间转移
✕持仓期间一直在扣资金费✓ 只有结算时刻持仓才付或收
✕有标记价格就不会被强平✓ 挡得住插针，挡不住真实下跌
✕合约价时刻等于现货✓ 两次结算之间可以偏离很远
  1. 最后理一理四个常见误区。误区一，资金费是交易所收的。不对，它只在多空之间转移，交易所不收。
  2. 误区二，持仓期间一直在扣资金费。也不对，只有在结算时刻持仓，才付或收。
  3. 误区三，有了标记价格就不会被插针强平。标记价格能挡住单一来源的插针，挡不住全市场的真实下跌。
  4. 误区四，资金费率能让合约价时刻等于现货。它每个周期才结算一次，两次结算之间，合约价可以偏离很远。
Summary

记住三件事

  • 永续没有到期日，靠资金费率锚定现货；正费率多付空，负费率空付多。
  • F = P + clamp(I − P, ±0.05%)，平静时常年 0.01%。
  • 强平看标记价格：三者中位数，挡插针，不挡真实下跌。

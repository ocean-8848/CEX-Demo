产品拆解

每个产品，都是五种底层能力的组合

产品托管记账撮合授信定价与对冲
所有产品都写进同一个账本。底层一出事，所有店铺一起停业。
  1. 先看产品。币安主站有几十个入口，但拆开看，底层只有五种能力。托管、记账、撮合、授信，还有定价与对冲。
  2. 现货最简单。币放在平台托管，成交靠撮合，所有权变化写进账本。
  3. 杠杆在现货上加了一层授信。平台先借钱给你，保证金兜底，按小时计息。
  4. 闪兑不走订单簿。平台直接给你报价，自己承担风险，再去市场对冲。
  5. P2P 和 Pay 基本不用撮合。P2P 靠账本冻结卖家的币，Pay 是账本内划转，不上链。
  6. 双币投资看起来像理财，本质是用户卖出一份期权。平台赚的是期权费的差价。
  7. 记住一点。所有产品最后都写进同一个账本。底层一出事，所有店铺一起停业。
算一笔账 · 示例数字

零手续费的闪兑，钱藏在价差里

用户支付1000 USDT
市场中间价2480 USDT/ETH
按中间价应得≈ 0.4032 ETH
闪兑报价 · 10 秒0.4000 ETH
差额0.0032 ETH
隐含费率≈ 0.8%
用户确认报价平台成为对手方
账本划转USDT 给平台，ETH 给用户
对冲服务现货市场买回 0.4 ETH
比喻：机场换汇柜台。
不准之处：闪兑用户会挑报价，只接受对自己有利的。
  1. 来算一笔闪兑的账。用户要用1000 USDT 换 ETH。
  2. 报价引擎先取市场中间价。举个示例，中间价是2480 USDT 一个 ETH。
  3. 按中间价，1000 USDT 能换大约0.4032个 ETH。
  4. 但页面报给你的是0.4个 ETH，10秒内有效。差出来的0.0032个 ETH，就是价差。
  5. 折算一下，这笔价差大约是0.8%。零手续费，不等于零成本。
  6. 用户确认后，平台成了你的对手方，手里多了一个反向敞口。对冲服务马上去现货市场买回0.4个 ETH。如果报价期间价格跳得太快，对冲的亏损由平台承担。
  7. 这像机场的换汇柜台，牌价里已含利润。比喻不准的地方是，闪兑用户可以比较外部价格，只接受对自己有利的报价。这就是报价被套利的风险。
收入构成 · 示例假设

一根柱子，堆出交易所的收入 示例假设

交易手续费 70%
熊市交易量下降 → 利息和理财收入占比上升。Coinbase 公开财报：交易收入长期占主要部分。
  1. 现在看整体收入。交易所有八类收入来源，示例图把它们合成七段，我们一段一段堆起来。
  2. 第一段，合约手续费，示例占45%。合约按名义价值收费，单笔名义价值通常很大。
  3. 第二段，现货手续费，示例占25%。两项加起来是70%，交易手续费是收入主体。
  4. 第三段，借贷利息和理财利差，示例占12%。
  5. 再加上闪兑与期权价差6%，法币通道与 P2P 4%。
  6. 最后是上币与生态的间接收入5%，其他3%，合计100%。
  7. 注意，真实比例会随牛熊剧烈变化。熊市交易量下降，利息和理财收入的占比会上升。上市交易所 Coinbase 的公开财报也显示，交易收入长期是主要部分。
净手续费 · 示例数字

1000 万毛手续费，到手还剩多少？

  1. 交易手续费不是成交额乘以一个费率这么简单。到手之前，要打好几次折。
  2. 举个示例。某月按费率表算出的毛手续费是1000万 USDT。VIP 等级越高费率越低，示例从0.1%降到0.02%，这已经算在加权费率里。
  3. 第一折，BNB 抵扣。用 BNB 付手续费，币安现货打75折。假设40%的手续费用 BNB 支付，平台少收100万。
  4. 第二折，返佣。假设一半手续费来自被邀请用户，返佣比例20%，再支出90万。
  5. 第三折，做市商负费率。顶级做市商挂单不但不交钱，平台还倒贴。示例支出60万。
  6. 最后净收入是750万，只有毛收入的75%。平台愿意少收，是为了换来 BNB 需求、新用户和更厚的订单簿。
护城河

飞轮的起点是流动性，不是手续费

刹车 1：费率过高 → 用户流失到竞品
刹车 2：补贴过多 → 利润下降
比喻：菜市场管理方。
不准之处：流动性有马太效应，零手续费也抢不走深度。
  1. 交易所为什么愿意倒贴？答案在飞轮效应。飞轮的起点是流动性，不是手续费。
  2. 流动性好，就是深度厚、价差小，用户的交易成本就低。成本低，更多用户和机构会加入。
  3. 用户多了，交易量增长。交易量增长，手续费收入增长。
  4. 手续费再拿去补贴做市和营销，流动性更好，飞轮转完一圈。交易量本身也会让订单簿变厚，这是中间那条捷径。
  5. 飞轮有两个刹车。费率太高，用户流失到竞品。补贴太多，利润被吃掉。
  6. 飞轮还会反转。一旦发生安全事故或监管处罚，用户撤离，流动性变差，又逼走更多用户。2022年的 FTX 就是这样。
  7. 打个比方，交易所像菜市场的管理方，摊位越多，顾客越多。比喻不准的地方是，流动性有很强的马太效应。新交易所即使零手续费，订单簿太薄，滑点成本仍然更高。

做市商收入 = 价差 + 返佣
平台成本 = 返佣支出
流动性提供者计划：考核深度、价差、在线时间，达标给挂单费率优惠
风险：剧烈行情撤单 → 要求极端行情最低在线率
  1. 流动性从哪来？主要靠做市商。做市商在买卖两侧持续挂单，赚取价差。
  2. 看一个示例订单簿。没有做市商时，买一49950，卖一50050，价差100。
  3. 做市商进场后，买一49995，卖一50005，价差缩到10。普通用户每次交易都更便宜。
  4. 做市商的收入是价差加平台返佣。平台的成本，就是这笔返佣。
  5. 根据币安公开资料，现货和合约都有流动性提供者计划。考核挂单深度、价差和在线时间，达标就给挂单费率优惠。
  6. 风险在于，行情剧烈时做市商会撤单，订单簿瞬间变薄。所以考核里通常要求极端行情下的最低在线率。

  1. 再看 BNB。根据公开资料，BNB 于2017年发行，初始总量2亿枚。
  2. 币安承诺通过销毁，把总量减少到1亿枚。
  3. 2021年底起，改用季度自动销毁。销毁数量按公式算，输入是当季 BNB 价格和出块数量。
  4. 同样从2021年起，链上还有实时销毁。BNB Smart Chain 每个区块都会销毁一部分 Gas 费。
  5. 据公开报道，2026年1月完成第34次季度销毁，约137万枚。销毁后总量约1.36亿枚。
  6. 需求侧有手续费抵扣、Launchpool、Gas 费和 VIP 门槛。平台少收的手续费，换来了用户持有 BNB 的意愿。
  7. 但这是双刃剑。BNB 需求和平台经营高度相关。平台出问题，BNB 需求也会同时下降。本集只讲机制，不评价投资价值。

  1. 看完收入，看成本。交易所的成本大致分六类。
  2. 技术成本以固定成本为主。撮合、账本、机房和研发，规模越大，边际成本越低。
  3. 合规成本随业务地区增长。营销和做市激励弹性大，牛市高，熊市低。
  4. 还有安全储备和客服运营。安全储备里最有名的，是 SAFU 基金。
  5. 根据币安公告，SAFU 于2018年7月设立，最初从交易手续费中提取10%注入。

  7. 这里有个陷阱。熊市交易量下降，技术和合规这些固定成本却不变，利润会快速下降。

常见误区

四个关于交易所赚钱的误解

✗ 零手续费等于免费✓ 成本藏在报价价差里
✗ 理财收益凭空产生✓ 来自借款人、质押奖励或平台补贴
✗ 飞轮只会越转越快✓ 信任危机会让飞轮反转
✗ 交易所收入很稳定✓ 随市场周期波动，禁令可让地区收入归零
  1. 来看四个常见误区。第一，零手续费等于免费。不对，成本藏在报价价差里。
  2. 第二，理财收益是凭空产生的。不对，收益一定来自借款人、链上质押奖励，或者平台补贴。
  3. 第三，飞轮一旦转起来，就只会越转越快。不对，信任危机会让它反转。
  4. 第四，交易所收入很稳定。不对，手续费随市场活跃度波动。一个地区的禁令，也可能让该地区收入瞬间归零。
本集小结

记住三件事

  • 产品 = 托管、记账、撮合、授信、定价的组合，最后写进同一个账本。
  • 手续费是收入主体，但要扣掉 BNB 抵扣、返佣、做市商返佣。
  • 飞轮靠流动性启动；合规与安全储备是进入市场的门票。

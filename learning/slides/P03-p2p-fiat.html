比喻：二手平台的担保交易。卖家先把货交平台保管，卖家确认收钱，平台才放货
比喻失效处：P2P 平台不代收法币 → 只能看收据，而收据可以造假
  1. 本集分两段。第一段是 P2P：规则、托管、状态机、仲裁、商业逻辑和反诈。第二段是法币充提通道。
  2. 先打个比方。P2P 像二手平台的担保交易。卖家先把货交给平台保管，买家线下把钱转给卖家。卖家确认收到钱，平台才把货交给买家。
  3. 比喻在一点上不成立。二手平台通常代收货款，而 P2P 平台不代收法币。所以平台只能看收据判断钱付没付。收据可以造假，付款人可以是别人，钱也可能来自诈骗。

  1. 先看角色。广告方也叫商家，发布广告：币种、价格、数量、限额、收款方式和付款时限。下单方浏览广告，选一个下单。
  2. 根据币安 P2P 用户交易政策，平台声明自己不是交易的一方。它托管加密资产，做中立的撮合和争议处理方。
  3. 规则很具体。买家必须在广告规定的时限内付款。卖家确认收到全额付款后，必须在15分钟内放币。付款账户户名，必须和买家实名一致。
  4. 用非实名付款方式的，至少暂停7天 P2P 权限，争议中由买家承担损失。没付款就点已转账，账户可能被暂停。
  5. 还有一组惩罚规则。买家未经同意取消订单，一天累计3次，当天不能再买。下单方连续5笔超时未付款，暂停买入24小时。广告方连续5笔，暂停发广告24小时。连续8笔，永久关闭广告权限。
Escrow Money Flow · 示例

币走账本，钱走银行

  1. 来看资金流，数字是示例。卖家资金账户里有1000 USDT 可用。买家下单的瞬间，系统冻结这1000 USDT。托管在账本上，就是冻结。
  2. 买家线下银行转账7200元，直接打到卖家的银行卡。这一步完全在银行体系里，平台账本里没有任何法币分录。
  3. 卖家确认收款，放币。冻结的1000 USDT 被扣减，同时记入买家资金账户。广告方的手续费，从这里扣。
  4. 如果超时或者取消，冻结的币解冻，回到卖家可用余额。所以托管只用到三个账本操作：冻结、解冻、扣减。
  5. 出错点全在法币这一侧。转账可能根本没发生，只是假截图。付款人可能是第三人。钱也可能是诈骗赃款。
Order State Machine

订单状态机：币在哪里

  1. 把它画成状态机，顶部这条是币的位置。买家下单，系统冻结卖家的币，进入待付款。
  2. 待付款时，买家可以取消。付款时限到期，系统也会自动取消。两种情况，币都解冻退回卖家。
  3. 买家付款后点已付款，进入已标记付款。卖家核对银行到账和户名，确认收款并放币，订单完成。
  4. 关键规则来了。进入已标记付款以后，系统不再自动取消。因为买家可能真的付了款，自动退币会让买家钱币两空。没付款，就别点已付款。
  5. 卖家超时不放币，买家可以申诉。卖家没收到款，也可以申诉。申诉期间，币一直冻结。
  6. 申诉后双方可以协商。协商不成，客服要求举证，仲裁员裁决。判定已付款，强制放币。判定未付款，解冻退回。最终只有两个出口。
Call Chain · 示意服务名

下单、放币、申诉

  1. 再看调用链，服务名是业界通用划分。买家下单，p2p 服务先问风控：买家 KYC、限额、黑名单。
  2. 通过后调用账本，冻结卖家1000 USDT，拿到一个锁定编号。然后给买家显示收款信息和倒计时，同时通知卖家。
  3. 卖家登录银行，核对到账和户名，回来点放币，并输入二次验证。放币不可逆，平台要确认是卖家本人。
  4. p2p 服务调用账本，扣减卖家冻结的币，给买家入账。它自己不保存余额。
  5. 如果卖家15分钟内不放币，买家发起申诉。申诉服务在裁决前不碰账本。裁决后，调用和正常流程相同的接口。
Arbitration · 业界通用做法 · 裁决为示例

仲裁：看证据链

  1. 申诉之后怎么判？业界通常这样处理。系统先锁定订单，双方不能再取消或放币。客服在订单聊天里要求举证，举证有时限，示例是24小时。
  2. 买家提供转账回单，以及显示双方户名的流水。卖家提供银行流水的全页录屏。
  3. 仲裁员比对四件事：金额、时间、付款户名、收款账号，是否和订单一致。然后裁决，并对违规方扣分、限权或封号。
  4. 看几类常见争议。卖家收款不放币，强制放币。买家假截图，解冻退回卖家，买家封禁。三方支付，卖家原路退款，订单取消。
  5. 注意，截图是最弱的证据，因为容易伪造。录屏和银行官方流水更强。仲裁员看的是证据链是否一致，不是单张图片。
Business Model · 公开报道 + 示例

平台为什么少收费

  1. 先看价格。P2P 价格由商家自己定，通常围绕现货价乘以汇率上下浮动。浮动幅度，反映法币出入金的难度和风险。
  2. 再看费用。公开报道显示，币安对下单方收0手续费。对广告方按市场和币种收0到0.35%，以官网费率页为准。
  3. 为什么少收？一是拉新，P2P 是很多地区的第一个入金入口。二是带动下游，用户买到 USDT 会去现货、合约和理财。三是竞争，商家随时可以换平台。
  4. 第四，平台不经手法币，没有支付通道成本。主要成本是客服仲裁和风控。
  5. 商家的账也算一下，示例。7.15元买入，7.22元卖出，每1000 USDT 赚70元。扣掉0.2%的手续费约14.4元，净赚约55.6元。商家承担的风险，是收到问题资金被冻卡。
Merchant · Fraud · 公开资料 + 业界通用做法

商家认证与三类核心风险

风险怎么发生谁受损平台防线
三方支付付款户名 ≠ 买家实名卖家：钱被认定为赃款户名一致 · 处罚
洗钱赃款经 P2P 换 USDT 提走卖家与平台KYC · 限额 · 图谱 · 上报

  1. 先看商家认证。根据币安公开资料，申请商家需要完成高级身份认证。根据地区，可能要缴保证金。退出后，保证金在7个工作日内全额退还。
  2. 业界通常这样用它。保证金提高违约成本，可以赔付受害方。认证标识帮用户挑选对手方。平台也能对商家做更严的资金来源审查。
  3. 再看三类核心风险。第一，三方支付。付款户名和买家实名不一致。真实户主报案后，卖家收到的钱会被认定为赃款。
  4. 第二，洗钱。诈骗赃款经过 P2P 换成 USDT 后提走。防线是 KYC、限额、交易图谱分析和可疑交易上报。
  5. 第三，冻卡。卖家收到的法币来自电信诈骗，银行或执法机关冻结卖家银行卡。平台无法直接解冻，只能提供订单记录配合核查。
Fraud Chain · 业界通用做法

回到开头：卡为什么被冻

  1. 回到开头的问题。看这条典型链条。诈骗分子骗受害人转账，钱进了他控制的账户。
  2. 他用这笔钱，以付款人身份转给 P2P 卖家，在平台上买币。
  3. 卖家确认收款，放币。USDT 进入买家账户，然后马上提到外部地址。
  4. 受害人报案，资金流水指向卖家的银行卡，银行卡被冻结。卖家的交易完全正常，但仍然受损。平台的托管只保护币，不保护钱。
  5. 平台能控制的，是放币、入账、提币这三步。只要卖家坚持户名一致，链条在放币前就会断。秒提是洗钱的强信号，平台可以设提币观察期。
  6. 局限也要说。诈骗分子如果用收购来的实名账户付款，户名一致规则就会失效。这时需要资金关系图谱分析。
Failure Cases

四个常见失败场景

场景系统表现处置
付款后忘点已付款时限到期自动取消，币解冻回卖家联系卖家退款 · 平台尽力协助
卖家收款后失联停在已标记付款，不自动取消买家申诉 · 强制放币
买家假截图卖家没核对就放币，不可逆追查成功率低
银行撤回付款放币后付款被冲正，账本已完成冻结买家剩余资产 · 配合调查
  1. 再看几个常见失败场景。买家付款后忘了点已付款，时限到期自动取消，币解冻回卖家。买家只能联系卖家退款，平台尽力协助，但不保证。
  2. 卖家收款后失联，订单停在已标记付款，不会自动取消。买家申诉，仲裁强制放币。
  3. 卖家没核对银行就放币，结果是假截图。币已划转，不可逆，追查成功率低。这是卖家最大的操作风险。
  4. 卖家放币后，付款被银行冲正。账本已经完成，平台只能冻结买家剩余资产，配合调查。
Fiat On/Off Ramp · 公开资料 + 业界通用做法

法币通道：平台真正经手法币

  1. 第二段，法币充提通道。用户选择币种和通道，比如欧元 SEPA 转账、银行卡、本地电子钱包。根据币安公开资料，可用通道按地区不同，由合作银行或持牌支付机构提供。
  2. 和 P2P 最大的不同是，这里平台通过合作机构，真正经手法币。所以账本里有法币科目，要和银行流水对账。
  3. 资金流是这样的。用户转账时附一个唯一参考码，钱进入平台的客户资金账户。合作机构发到账通知，法币网关按参考码匹配用户，记入欧元余额。
  4. 状态机有两个分支。参考码缺失，资金进入待人工认领。付款户名和实名不一致，业界通常原路退回，不入账。
  5. 注意，已入账之前，钱在客户资金账户里，但不属于任何用户余额。对账时，它是一个单独的在途科目。
Reconciliation · 业界通用做法 + 示例

回调幂等与日终对账

  1. 系统怎么防错？到账回调可能重复，也可能丢失。法币网关按回调编号幂等去重，再做户名比对和反洗钱筛查。
  2. 对账服务每天拉取日终银行流水，和账本里的法币科目逐笔比对，有差异就报警。回调丢失的单子在这里被发现，人工补入账。
  3. 定价举个示例。某地区 SEPA 充值免费，银行卡充值收1.8%。平台在 SEPA 上不赚钱，用免费入金换后续的交易手续费。
  4. 最大的风险是银行合作中断。根据公开新闻，2023年前后，美国多家对加密友好的银行出了问题或收缩业务。多家交易所的美元通道因此受影响。
  5. 业界通常每个地区至少备两家合作机构。客户法币要和平台自有资金隔离，定期审计。对账差异，要在下一个工作日内清零。
本集小结

记住三件事

  • P2P 托管 = 冻结 · 解冻 · 扣减；难点在账本之外的证据。
  • 已标记付款后不再自动取消；托管只保护币，不保护钱。
  • 法币通道真正经手法币：参考码 · 幂等回调 · 日终对账。

下一集 P04 · 合约进阶：统一账户、组合保证金与期权
  1. 小结三点。第一，P2P 托管在账本上，只是冻结、解冻、扣减。难点不在账本，而在账本之外：钱有没有付，只能靠证据。
  2. 第二，已标记付款之后不再自动取消，申诉期间币保持冻结。托管只保护币，不保护钱。户名一致和提币观察期，是两道关键防线。
  3. 第三，法币通道里，平台真正经手法币。参考码匹配、幂等回调和日终对账，缺一不可。单一通道是系统性风险。
  4. 下一集，我们进入合约进阶：统一账户、组合保证金和期权。看平台怎样把多个仓位、多种资产，放进同一个风险框架。

  1. 你在交易所存了1000 USDT 活期，页面写着年化5%，这是示例。一年多出来的那笔钱，到底是谁付的？
  2. 答案是，理财产品本身不创造收益。它把你的闲置资产交给一个付费方，再把付费方的钱分给你。付费方只有三类：借款人、区块链网络、平台的营销预算。
  3. 这一集，我们按付费方拆开币安的理财产品。先说明，本集内容不构成投资建议。收益率会变化，质押资产有价格风险和赎回等待期。数字除公开资料外都是示例。

  3. 打个比方。理财像代收房租的中介。你把空房交给中介，它租给租客，或者换政府补贴，扣一部分再给你。开业时还送首月返现。
  4. 比喻在哪里不成立？房子始终是你的，可理财账户里的币，是你对平台的债权。租客跑路，或者所有房东同时收房，中介就会出问题。

  1. 先看 Simple Earn。根据币安公开资料，活期随时申购，随时赎回，但单日赎回有额度上限。定期要选期限，到期自动返还，可以自动续期。
  2. 活期收益分两层。实时 APR 是基础收益率，可以每分钟变化。阶梯 APR 是额外奖励，只对限额内的资产生效。定期是固定 APR。APR 都按单利折算。
  3. 阶梯 APR 有个陷阱。示例，前500 USDT 额外加5%。你存10000，只有500享受奖励，另外9500只拿实时 APR。整体收益率远低于宣传的最高值。
  4. 定期提前赎回也有代价。根据币安公开资料，平台没收期限内已发放的全部收益，从返还本金里扣除。剩余本金在72小时内回到现货账户。
Money Flow · 分配比例未公开

申购只是记账，钱进了资金池

  1. 申购的时候发生了什么？只是账本内部划转，从现货账户到理财账户。链上没有任何转账，币还在平台的同一组钱包里。
  2. 账本记一笔对用户的负债，资产进入平台的理财资金池。资金池把钱分到三处：出借给杠杆和借贷用户，链上质押，再留一部分缓冲应对赎回。分配比例币安没有公开。
  3. 收入从两头回来，借款人付利息，链上质押发奖励。再加上营销预算付的补贴，一起进入每日计息批处理，发给用户。
  4. 所以用户收益，等于借款利息加质押奖励加营销补贴，再减平台利差。出错点在缓冲。赎回量超过缓冲，平台就要提前收回借款，或者动用自有资金。
Utilization Pricing · 业界通用做法 · 示例

同一个资金池的两面：借款利率与理财 APR

  1. 活期的实时 APR 由借贷需求决定。业界通常按资金使用率定价，和 P01 的借贷利率是同一个资金池的两面。使用率等于已借出除以资金池总额。
  2. 使用率越高，借款利率越高。理财基础 APR，等于借款利率乘以使用率，再乘以1减平台抽成。
  3. 代入示例。资金池1亿 USDT，借出7000万，使用率70%。借款年利率10%，平台抽成20%。理财基础 APR 等于10%乘70%乘80%，就是5.6%。
  4. 再加营销补贴。示例阶梯 APR 是前500 USDT 加4%。存500的用户看到9.6%，存10万的用户整体约5.6%。
  5. 平台每年的利差收入，是7000万乘以10%再乘20%，140万 USDT。使用率接近上限时，借款利率会陡升，逼借款人还款，给赎回腾出空间。
Call Chain · Ledger · 组件与科目名为示例

申购、计息、赎回：三种分录

  1. 系统里怎么实现？我们新增示例服务 earn-service。用户申购1000 USDT，先查额度和地区限制，再记账。借记现货可用，贷记理财持仓，平台总负债不变。
  2. 计息是异步批处理，示例在 UTC 0点。收益等于份额乘 APR 除以365。1000乘5%除以365，约0.137 USDT。借记平台利息支出，贷记用户理财持仓。
  3. 赎回400，是反方向的内部划转。注意一个竞态，检查额度和记账之间可能被并发打断。业界通常用数据库行锁，或者额度服务的原子扣减。
  4. 计息批处理有三条要求。第一，用快照计息。第二，每人每天一条分录，幂等键含用户、产品和日期，重跑不会重复发息。第三，利息总额和支出科目核对相等，才提交。
  5. 还有个细节。实时 APR 按分钟累计，如果每分钟记一笔账，分录会爆炸。业界做法是按分钟算应计利息，在汇总表累加，按日或赎回时一次记账。
Risk · Hedge · Failure

活期负债随时可取，资产却有期限

  1. 平台承担三种风险。期限错配，活期负债随时可取，资产却有期限。借款人违约，靠强平和保险基金兜底。还有挤兑。
  2. 示例。资金池留10%到20%做流动性缓冲。平常的赎回，缓冲足够应付。
  3. 赎回突然放大，超过当日额度，多出来的请求进入排队，等次日额度恢复。同时使用率逼近上限，借款利率陡升，逼借款人还款。最后一道防线是平台自有资金。
  4. 根据公开报道，2022年 Celsius 把存款投入高风险借贷和 DeFi。资产下跌后用户集中赎回，Celsius 暂停提款，随后破产。理财资产是对平台的债权，破产时要排队受偿。
  5. 再看一个工程故障，示例。计息批处理没有幂等键，重跑之后，每个用户收到两份利息。正确修复是记冲回分录，而不是修改历史流水。
Liquid Staking · Non-rebasing

数量不变，汇率在涨

  1. 第二组，链上质押。根据币安公开资料，质押 ETH 收到 WBETH，质押 SOL 收到 BNSOL。它们叫流动性质押代币，代表质押中的币加累计奖励，可以交易和做抵押。
  2. 收益怎么体现？WBETH 数量不变，汇率在涨。根据币安公开说明，1个 WBETH 等于1个质押中的 ETH，加上累计奖励。奖励从2023年4月27日开始累计。
  3. 示例。汇率1.05时，质押10.5 ETH。除以1.05，收到10个 WBETH。
  4. 当日网络奖励率示例是3%除以365，服务费5%。新汇率等于旧汇率乘以1加净奖励率。按单利近似，一年后汇率约1.0799。
  5. 用户仍然持有10个 WBETH，但能换回约10.799个 ETH。这叫非变基设计。WBETH 放进合约或做抵押时，余额不会自己变，便于记账。
Staking Flow · Unstaking Queue

质押：32 ETH 一批，赎回要排队

  1. 质押的资金流是这样的。账本扣 ETH，发 WBETH。平台把零散的质押汇总，按32 ETH 一个验证者批量存入链上，这是以太坊的规则。
  2. 链上奖励由以太坊网络支付，不是平台付。平台抽5%服务费，其余通过汇率更新任务，每天上调汇率。汇率更新是单点，发错会影响所有持有人，业界通常双人复核。
  3. 赎回要排队。申请赎回10 WBETH，系统先冻结，再提交验证者退出。以太坊每个周期只允许有限的验证者退出，要等数天到数周。完成后才扣减 WBETH，按当时汇率记入 ETH。
  4. 不想等，可以在现货市场卖出 WBETH，立刻拿到钱。但价格由市场决定，可能低于汇率。这就是状态机的两条出路，排队赎回，或者市场卖出。

Failure Case · 公开报道

订单簿价格不可信时，强平会自我加速

  1. 脱锚真的发生过。根据公开报道，2025年10月10日市场剧烈下跌。UTC 21点36分到22点16分，三种资产出现价格偏离。它们是币安的 USDe、WBETH 和 BNSOL。
  2. 链条是这样的。全市场暴跌，流动性枯竭，本所 WBETH 订单簿被大额卖单砸穿。
  3. 保证金估价主要引用本所现货价格。于是 WBETH 的抵押价值骤降，可它对 ETH 的汇率根本没变。
  4. 保证金率跌破维持线，系统强平卖出 WBETH，又进一步压低订单簿价格，形成循环。用这些资产做统一账户保证金的用户被强平，币安随后补偿了受影响用户。
  5. 改进方向是以汇率为基准，市场价为参考，引入多源价格，参数以官网为准。但纯用汇率也有风险，排队期内汇率无法立即兑现，所以还要加折扣率。
Auto-Invest · DCA

定投不是收益产品，是定时下单工具

  1. 第三组，定投。按固定周期，用固定金额买入，到点自动扣款，买到的币可以转入活期。注意，定投不是收益产品，收益完全取决于价格走势。
  2. 据公开报道，币安在2025年把定投迁移到闪兑的定期买入。原计划2025年3月31日下线，指数定投11月27日退役。定期买入按闪兑报价成交，不另收兑换手续费。
  3. 系统里，调度器触发14点批次，用计划号加期号做幂等键，逐个冻结用户 USDT。示例汇总5000个计划，共200万 USDT，提交一笔聚合市价单。
  4. 成交均价100050，所有用户按同一个均价，按金额比例分配 BTC，保证公平。余额不足的计划跳过本期，下期也不补买。
  5. 平台赚手续费或价差。示例每周100 USDT，费率0.1%，一年52期，收入5.2 USDT。常见故障是整点拥堵。解决办法是打散触发时间，再加价格保护。
BNB Vault · Simple Earn BNB

一份 BNB，三种收益

  1. 第四组，BNB Vault。根据公开报道，它在2020年11月上线。存入 BNB，同时拿活期利息、Launchpool 新币奖励和活动奖励。后来它整合进 Simple Earn BNB。持有它，就能参与 Launchpool 和 HODLer 空投。
  2. 新币奖励由项目方支付，换取曝光和用户。系统示例每小时快照一次 BNB 持仓，用户份额等于用户 BNB 除以全池 BNB。快照越密，快照前存入、快照后取走的套利空间越小。
  3. 示例。奖励100万个新币，用户份额0.01%，新币价格0.5 USDT。用户拿到50 USDT。宣传 APR 随全池规模和币价大幅波动，只是估算。
  4. 还有监管风险。根据公开法律文件，2023年美国 SEC 起诉币安。BNB Vault 和 Simple Earn 被列为未注册证券发行。这会迫使平台按地区下线产品。

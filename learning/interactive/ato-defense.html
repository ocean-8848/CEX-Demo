盗号攻防实验

选择一个盗号剧本，打开或关闭左侧的防线，然后发动攻击。观察攻击在哪一步被拦住、被哪道防线拦住，以及这道防线让正常用户多付出多少体验成本。目标是找到"拦得住"和"不烦人"之间的平衡点。

怎么玩： 1. 在左侧勾选防线。每道防线右侧的数字是它的"摩擦分"（正常用户的体验成本）。 2. 在上方选择攻击剧本。 3. 点"发动攻击"，看攻击链逐步推进。绿色 = 硬拦截；橙色 = 软拦截（依赖用户自己醒悟，按 0.5 计）；红色 = 资产被盗。 4. 看下方统计面板：拦截率按全部 5 个剧本计算，摩擦分是全部已开防线的成本之和。

    2. 试一试

    试一试 A：只靠一把锁

    点"全关"，然后只打开 Passkey。分别运行 5 个剧本。Passkey 拦住了哪几个？为什么它对"恶意插件盗 API Key"和"客服冒充"无效？

    试一试 B：邮件确认为什么失效

    只打开"提币邮件确认"，运行"钓鱼站"和"撞库"。同一道防线，为什么一个拦住、一个漏过？再打开"改密后冷却"，钓鱼站剧本在哪一步被拦？

    试一试 C：找平衡点

    只拦住一次不够可靠。找出一组防线：除"客服冒充"外，每个剧本都有至少 2 道硬拦截（看矩阵最后一列），且摩擦分最低。最低能做到几分？为什么"客服冒充"始终只能软拦截？回到 B03 第 7 节，想想技术之外还能做什么。

    本页是教学模型。拦截关系和摩擦分是简化的示例值，用于说明"纵深防御"与"体验成本"的权衡，不代表币安的真实规则或参数。 攻击链只描述到理解防线所需的程度。阅读 B03-account-security.md 了解完整说明。
